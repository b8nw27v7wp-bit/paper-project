# 第3章 系统需求与总体设计

> 版本 v0.2_20260826 增补 | 14视图 16组路由 92%

## 3.1 需求分析
- 功能：learning_goal/task CRUD、周计划生成、日历拖拽、批量改期、反思报告
- 非功能：P95 <300ms、SSE <2s 首字节、Electron 启动<3s、并发 WAL
- 约束：查重<15%、Docker 一键启动、桌面安装包<200MB

## 3.2 用例与用户故事
- 学生：创建目标 → 生成计划（多Agent）→ 执行打卡 → 查看反思 → 下周减负
- 导师：查看大屏完成率/拖延率/负荷/图谱热力，盲评实验合理性
- 管理员：健康探针 /health、性能指标 X-Response-Time

## 3.3 总体架构（4层）
- 表现层：Web（Vite）+ Electron（IPC bridge）+ CLI（Typer --json）
- 业务层：agents/graph（6节点）、services（planner/memory/stats/performance）
- 数据层：PG/SQLite + pgvector + Neo4j + Redis + MinIO
- 基础设施：Docker Compose、APScheduler（周日23:00 + 周一09:00）

## 3.4 模块划分与职责
- app/agents/tools/registry.py：4工具可热插 memory/rag/graph/write
- app/api/v1/*：goals/tasks/plans/memory/rag/graph/mcp/multimodal/reflection/stats/experiments/desktop
- app/services/*：planner、memory、stats、experiments、performance（LRU+timed）
- app/scheduler/reflector.py：generate_reflection + weekly_summary + register_jobs

## 3.5 数据模型
- learning_goal（id/title/deadline/subject/user_id）
- task（goal_id/title/planned_start/planned_end/priority/status/citations）
- memory_chunk（user_id/type/embedding[1536]/content）
- reflection_report（user_id/week/completion_rate/delay_rate/analysis/patch）
- agent_run_log（trace_id/agent_name/input/output/tool_calls）
- window_state（本地 better-sqlite3，云端代理内存）

## 3.6 接口与交互设计
- POST /plans?mode=multi → SSE /plans/stream?trace_id（Last-Event-ID断点续传）
- GET /graph?subject&keyword、POST /mcp/call、POST /multimodal/ocr
- GET/PUT /desktop/window-state、POST /desktop/notify（Electron 同步）
- 前端 apiClient baseURL /api/v1，rootClient /health

## 3.7 安全与非功能设计
- 鉴权：Authorization Bearer JWT 优先，X-User-Id 仅 dev/pytest
- CORS：debug 明示本地源，prod 过滤 app://*
- DB：WAL + busy_timeout=5000，pgvector HNSW
- 打包：extraResources/server + externalBin/bin + asarUnpack better-sqlite3

## 3.8 本章小结
- 明确闭环链路与分层职责，为第4-6章实现奠定模型与接口契约
