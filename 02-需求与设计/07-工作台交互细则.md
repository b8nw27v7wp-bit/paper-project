# 工作台交互细则 — F15 Chat 配套

> 版本：v1.1_20260908 | 02-需求与设计 | 归属：F15 Agent工作台-Chat | 上游：01-需求分析.md F15-UX1~UX3 | 视觉风格遵循 06-UI设计规范.md（Apple 系统字体栈 · #1d1d1f · 白底无框 · 大留白 · 高级克制）
> 落点：`apps/frontend/src/views/AgentWorkbenchView.vue` + `stores/sessions.ts` / `stores/workbench.ts` / `components/ShortcutsPanel.vue` + `views/DashboardView.vue` / `views/ReflectionView.vue`

## 1. 会话自动命名

- **描述**：会话 done 后左栏标题自动生成易读小结，免手动命名；手动改名优先且永不被覆盖。
- **规则**：done 后调 `POST /api/v1/llm/summarize`（入参目标标题+前3任务标题，`max_len=12`），成功写入 `sessions.ts names`（`auto:true` 标记）；无 key/失败/超时回退“目标截断10字+共N任务”拼装；已有手动名（`auto` 为空）直接跳过。刷新持久（localStorage）。
- **验收**：done 后 1s 内左栏显示自动名；手动改名后不再覆盖；刷新仍在；无 key 环境回退拼装可用。

## 2. 上下文用量条

- **描述**：Composer 输入框上沿通栏 2px 进度条，实时展示本会话上下文占用，逼近阈值时可预期 compact。
- **规则**：用量 `= max(事件数/20, 字符数/8000)`，阈值与后端 `app/agents/compaction.py THRESHOLD=20 / CHAR_BUDGET=8000` 同源声明（改后端必须同步改前端常量，文件头注释锁死）；事件数取转录长度（200 封顶即满），字符数取全部文本/话术/任务标题求和；三段色 灰（<60%）/黄（60–85%）/红（>85% 附“将压缩早前记录”）；hover 显示“事件 x/20 · 约 y/8000 字”；收到 `compact_summary` 后仅统计其后新增（即回零）。
- **验收**：与后端压摘要触发点误差 ±1 事件；压缩后回零；纯前端派生，不新增接口。

## 3. Composer 分组

- **描述**：输入区 8 控件（目标/模式/审批/时长/模型/附件/语音/发送）分组，外露常用、收起低频，小屏不挤占输入。
- **规则**：外露 发送/模型/附件`＋`；“更多”下拉收 目标/模式/审批/时长，语音为禁用占位（“语音席位待开放”，接通 ASR 后启用）；`<1024px` 强制只留 发送+更多；`send()` 签名与全部控件逻辑不动。附件走真上传（`ingestRag`，成功回填 chip 最多 5 个，发送时拼入目标描述）。
- **验收**：功能无删减；375px 下无页面级横滚；更多下拉 Esc 关闭。

## 4. 草稿守护

- **描述**：切换页面或误关不丢输入草稿。
- **规则**：composer 输入 500ms debounce 写 `localStorage workbench:draft`（空则删键）；发送成功/新会话清空；挂载回填；`App.vue` 全局 `beforeunload` 探针（key 非空才提醒）。
- **验收**：切页回来草稿仍在；关页/刷新有提醒；发送后不残留。

## 5. 快捷键表

- **描述**：工作台路由内键盘优先操作，与桌面端通道对齐。
- **规则**：`N` 新会话（调 `newSession`，映射桌面 `agent:new-session`）、`/` 聚焦输入框、`J`/`K` 按会话列表顺序切会话（复用 `replaySession`）、`Ctrl+K` 命令面板、`?` 快捷键表；input/textarea 内不劫持（`/`/`N` 等可正常输入）；`J`/`K` 为 Web 独有（桌面端无对应通道）；`ShortcutsPanel.vue` 同步四项说明。
- **验收**：面板与实现一致；输入框内按键无劫持；桌面 ⌘N/⌘I 行为不变。

## 6. 年热力图

- **描述**：Dashboard 趋势图下方一年打卡浓度一览（GitHub 式）。
- **规则**：独立调 `trend` 接口 `range=365d`（一次请求，与 7d/30d 切换逻辑互不影响）；53×7 格，列=周、行=周一到周日（首日偏移补空）；强度四档 0 / <0.4 / <0.8 / ≥0.8，对应 `#ebedf0/#9be9a8/#40c463/#216e39`，暗色走 `chartTheme` 降透明度映射；hover 显示日期+完成率；空数据空态。
- **验收**：一次请求渲染；暗色可读；与 trend 接口字段（dates/rates/loads）一致。

## 7. 专注卡

- **描述**：反思页三统计卡旁第四卡，展示**本周**专注时长。
- **规则**：读 `overview`（`range=7d`）的 `focus_seconds` 字段（后端 `stats.py overview()` 求和本周 `delay_reason='pomodoro'` 日志，零迁移），显示 `x.x 小时`；0 或缺字段时空态“暂无专注记录，去任务抽屉记一个番茄”附跳 `/calendar` 按钮；样式与三卡一致。
- **验收**：数值与番茄上报一致（上报 300 秒即 +0.1 小时级）；空态可跳转。

## 8. 一键导出

- **描述**：周报三种带走形态：复制 Markdown / 下载 `.md` / 打印。
- **规则**：复制内容由 report（week/completion_rate/delay_rate/avg_load/analysis/patch）拼可读文档（clipboard 失败用 textarea 兜底）；下载 Blob 命名 `周反思-<week>.md`；打印调 `window.print()`，`style.css @media print` 只留 `.print-report` 报告区（含报告内按钮一并隐藏）；无报告时 warning 不执行。
- **验收**：三项可用；打印预览仅报告区；中文无乱码。
