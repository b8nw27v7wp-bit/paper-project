## 1. 引言

### 1.1 编写目的
本文档作为毕设《基于多智能体协作与记忆增强的自进化学习任务规划与管理的智能体》的需求基线，明确功能/数据/非功能需求，供架构设计、数据库设计、接口设计、测试与论文第3章直接引用。

### 1.2 项目背景
传统Todo/日历工具静态、通用、无反馈；单Agent对话易幻觉、缺记忆、无法调工具。本系统以Electron+FastAPI为底座，引入LangGraph多智能体、pgvector长期记忆、Neo4j知识图谱、MCP工具链、多模态感知与APS cheduler反思，实现感知-规划-执行-反思闭环。

### 1.3 术语

| 术语 | 说明 |
|------|------|
| Goal | 宏观目标，如"30天过六级，2026-09-30截止" |
| Task | 可执行日任务，含起止时间、优先级、引用 |
| Memory | 长期记忆，pgvector存偏好/拖延/薄弱点 |
| Chunk | 知识切片，512字符切块 |
| Knowledge | 知识点，Neo4j节点 |
| Trace | 一次规划的协作轨迹，关联agent_run_log |
| Citations | 任务引用的知识证据 |

### 1.4 参考资料
- LangGraph、MCP协议、pgvector、Neo4j文档
- Codex Desktop架构（Electron 40 + Rust CLI + IPC 70方法）
- `00-管理/00-项目总计划书.md`、`01-开题与立项/01-题目与技术栈说明.md`

## 2. 项目概述

### 2.1 产品定位
面向大学生/考研/考证人群的本地优先学习规划智能体 Studying-Planner，Web/桌面/CLI三端复用同一FastAPI，答辩以Web为主、桌面演示智能体工作台能力。

### 2.2 用户特征

| 角色 | 画像 | 核心诉求 | 使用频率 |
|------|------|----------|----------|
| 学习者 | 20-26岁，日均学习2-4h，多目标并行 | 个性化、可执行、少手动、有反馈 | 日活 |
| 管理员 | 运维 | 配置模型/MCP、看监控 | 周活 |
| 访客 | 未登录 | 体验Demo | 偶发 |

### 2.3 运行环境
- 客户端：Win10+ (WebView2)、macOS14+，Chrome>=110
- 服务端：Python 3.11, Node>=22, Docker (PG16+pgvector 0.7, Neo4j 5, Redis 7), Electron 40

### 2.4 约束
- 单人28周，模型用云端API，非本地部署
- 数据量：<1万Goal，<10万Task，<5万Chunk，<1万图谱节点
- 网络依赖LLM，离线仅查历史

## 4. 详细功能需求（每点写全）

### F01 目标管理（P0）

- **描述**：学习者创建/编辑/归档宏观Goal，作为规划输入。
- **前置**：已登录
- **输入**：title(1-200,必填), description(0-2000), deadline(必填,>now+1天), subject(可选)
- **基本流**：1.点击新建 2.填表单 3.校验 4.POST /goals 5.列表刷新
- **备选流**：编辑->PUT /goals/{id}；归档->status=archived；删除->二次确认
- **异常**：标题空/截止<now+1天 -> 提示；重名 -> 允许
- **后置**：生成Goal，进入待规划
- **验收**：可创建/编辑/归档，分页20，截止校验生效
- **优先级**：P0

### F02 多Agent智能规划（P0, 核心）

- **描述**：输入Goal由智能体自主规划（SystemAgent.ainvoke）生成周/日Task，展示协作轨迹。
- **前置**：Goal存在且active
- **输入**：goal_id, preferences{每日可用时长, 偏好时段}(可选)
- **基本流**：1.点击智能规划 2.SSE订阅 3.FastAPI LangGraph: Planner(检索记忆Top5+图谱PREREQ+向量Top10) -> Executor生成Task[] -> Critic校验(冲突/负荷/依赖) -> Mentor话术 4.SSE推thought/tool_call/task_created 5.渲染甘特图/日历 6.MCP同步
- **备选流**：Critic驳回->Planner重规划最多2轮；用户手动拖拽改时间->Critic二次校验
- **异常**：LLM超时15s->重试1次；MCP失败->降级仅本地；SSE断线->重连
- **后置**：生成Task[]，写入agent_run_log(trace_id)，可打卡
- **验收**：同Goal 3次规划结果稳定，首字节<2s，全程<15s，Critic拦截率>20%（测试集），日志可追溯
- **优先级**：P0

### F03 任务执行与打卡（P0）

- **描述**：对日Task打卡、记时长与拖延原因，供记忆与反思。
- **前置**：Task存在
- **输入**：task_id, actual_duration(0-600), completion_rate(0-1), delay_reason(0-500,可选), status(todo/doing/done/delayed)
- **基本流**：1.日历/列表点击任务 2.开始->doing 3.完成->done填时长与完成率 4.POST /tasks/{id}/complete 5.写task_execution_log
- **备选流**：拖延->delayed必填原因；批量完成
- **异常**：时长负数->校验；完成率>1->校验
- **后置**：更新Task状态，触发记忆摘要
- **验收**：可流转4状态，统计准确
- **优先级**：P0

### F04 长期记忆管理（P0）

- **描述**：自动沉淀与检索个性化记忆，注入规划。
- **前置**：有执行日志
- **输入**：用户行为（拖延、偏好时段、薄弱点）
- **基本流**：1.任务完成后摘要Prompt生成记忆 2.Embedding入pgvector memory_chunk(type=memory) 3.规划前cosine>0.75 Top5检索 4.注入Planner
- **备选流**：用户手动增删记忆；每日22:00批量摘要
- **异常**：Embedding失败->重试
- **后置**：记忆数增长，下次规划更个性化
- **验收**：有/无记忆7日完成率对比+15%（实验B），检索<1s
- **优先级**：P0

### F05 RAG知识入库（P0）

- **描述**：上传PDF/图片切块入库，供证据式规划。
- **前置**：已登录
- **输入**：file(PDF/JPG/PNG, <20M), subject(可选)
- **基本流**：1.上传MinIO 2.切块512+overlap50 3.Embedding入pgvector(type=knowledge) 4.LLM抽三元组入Neo4j 5.返回{chunks, knowledges}
- **备选流**：图片先Qwen-VL OCR再切
- **异常**：文件超限/格式错->提示；抽取失败->仅存向量
- **后置**：可被检索与图谱查询
- **验收**：100页PDF <60s，Top10召回>70%
- **优先级**：P0

### F06 知识图谱与可视化（P0）

- **描述**：展示知识点先修关系，支撑依赖校验。
- **前置**：已入库知识
- **输入**：subject, keyword
- **基本流**：1.GET /graph 2.Neo4j MATCH PREREQ 3.ECharts Graph渲染 4.点击节点联动检索
- **异常**：无图谱->空状态引导上传
- **后置**：Critic用图谱校验依赖
- **验收**：<1万节点渲染<3s，PREREQ查询<500ms
- **优先级**：P0

### F07 MCP日历/待办同步（P1）

- **描述**：规划后自动创建日历事件/待办。
- **前置**：MCP Server已配置
- **输入**：task{title, start, end}
- **基本流**：1.Executor判断需同步 2.mcp:call create_event 3.成功写task.source_agent=mcp:calendar，否则降级
- **备选流**：用户关闭同步->仅本地
- **异常**：MCP超时5s重试1次，失败提示
- **后置**：日历可见事件
- **验收**：成功率>95%，失败不阻断规划
- **优先级**：P1

### F08 番茄钟（P1）

- **描述**：关联Task的专注计时。
- **前置**：Task为doing
- **输入**：task_id, duration(25/50)
- **基本流**：1.点击开始 2.倒计时 3.暂停/完成 4.写actual_duration
- **异常**：页面刷新->从Redis恢复
- **验收**：计时准确，统计入周报
- **优先级**：P1

### F09 多模态拍照/截图识课表（P2）

- **描述**：拍照课表/错题自动建Goal/Task。
- **前置**：已登录
- **输入**：image(JPG/PNG <10M)
- **基本流**：1.Electron选文件/截图 2.POST /multimodal/ocr 3.Qwen-VL JSON {course,time} 4.确认后create_goal
- **异常**：OCR置信<0.6->人工纠错
- **验收**：课表识别>80%，错题>70%
- **优先级**：P2

### F10 语音输入（P2）

- **描述**：语音转文字建任务。
- **前置**：已授权麦克风
- **输入**：audio(webm <5M)
- **基本流**：1.录音 2.POST /multimodal/asr(Whisper) 3.回显文字 4.一键规划
- **异常**：无声->提示重录
- **验收**：中文WER<15%
- **优先级**：P2

### F11 周反思与自进化（P1）

- **描述**：每周自动生成复盘与下周补丁。
- **触发**：APScheduler 0 23 * * 0 + 手动POST /reflection/run
- **基本流**：1.读本周task_execution_log 2.算完成率/拖延率/负荷 3.LLM生成analysis+next_plan_patch 4.写reflection_report 5.推送通知 6.下周Planner合并patch
- **异常**：本周无数据->生成空报告；LLM失败->保留上周patch
- **后置**：下周计划自动优化
- **验收**：每周生成1份，patch生效后下周完成率不降
- **优先级**：P1

### F12 可视化大屏（P1）

- **描述**：一览学情。
- **输入**：range(7d/30d)
- **基本流**：GET /stats/overview + /trend -> ECharts折线/饼图/甘特
- **验收**：3类图<2s
- **优先级**：P1

### F13 三端适配（P1）

- **描述**：Web/桌面/CLI共用后端。
- **基本流**：同Vue代码build:web/build:electron；CLI Typer调HTTP
- **验收**：同一Goal三端数据一致
- **优先级**：P1

### F14 系统通知与设置（P1）

- **描述**：桌面通知、Token、模型/MCP配置。
- **基本流**：Electron Notification + Keyring存Key + 设置页改MCP地址
- **验收**：通知可达，Key不落地明文
- **优先级**：P1

### F15 Agent工作台-Chat（P0）

- **描述**：三栏(会话列表/Chat对话/Inspector可折叠子调用)双轨工作台，提供流式协作可视与重连能力。
- **前置**：已登录，Goal存在(可选)
- **输入**：prompt(1-2000,必填), goal_id(可选,关联F01)
- **基本流**：1.输入prompt点击发送 2.SSE订阅事件流 thought/tool_call_start/tool_call_end/task_created 3.并行展示researcher 3子调用卡片(可折叠) 4.支持Last-Event-ID断线重连续推
- **备选流**：无goal_id->纯对话规划；手动重试->重发prompt；折叠Inspector->仅看Chat
- **异常**：LLM超时15s->重试1次；SSE断线->Last-Event-ID重连；重试仍失败->提示
- **后置**：生成会话与trace_id，写入agent_run_log，关联Task[]
- **验收**：SSE首字节<2s，全程<15s，3子调用并行可视，Critic拦截可视，重连不丢事件
- **优先级**：P0

#### F15-UX1 会话自动命名

- **描述**：会话 done 后自动生成易读标题，免手动命名。
- **规则**：LLM 调 `/llm/summarize` 生成；失败回退“目标截断+共N任务”拼装；手动名优先永不覆盖。
- **验收**：done 后显示自动名、刷新持久。

#### F15-UX2 上下文用量条

- **描述**：展示当前会话上下文占用，逼近阈值时可预期 compact。
- **规则**：阈值与后端 `compaction.py THRESHOLD=20/CHAR_BUDGET=8000` 同源声明；三段色；compact 回零。
- **验收**：误差±1 事件。

#### F15-UX3 审批双入口+pending 发现

- **描述**：审批在常用路径双入口可达，pending 到达时主动发现引导。
- **规则**：审批双入口+pending 自动发现引导（badge/横幅一键定位）。
- **验收**：双入口均可达审批，pending 有提示且可一键定位，无静默 pending。

### F16 知识图谱-编排可视化 Graph（P0）

- **描述**：渲染6节点DAG(Planner/Researcher/Executor/Critic/Mentor/Reflector)含rewrites回边，提供编排级可视与论文导图能力。
- **前置**：trace_id存在，已有agent_run_log
- **输入**：trace_id(UUID,必填)
- **基本流**：1.GET /plans/{trace_id}/logs 拉取6条轨迹 2.前端构图DAG含rewrites回边 3.节点态pending/running/success/error着色与连线动画 4.点击节点穿透至Inspector对应agent详情
- **备选流**：无rewrites->不渲染回边；Critic驳回->高亮error并展示回边至Planner
- **异常**：trace_id不存在->空状态；日志缺失->部分节点置pending
- **后置**：图谱可导出PNG/SVG用于论文
- **验收**：6节点渲染<500ms，连线与状态与日志一致，支持导图用于论文
- **优先级**：P0

### F17 追溯-Inspector（P0）

- **描述**：展示PlanState全量+tool_calls+_patch+citations的追溯面板，支撑可复现与论文取证。
- **前置**：trace_id存在
- **输入**：trace_id(UUID,必填), agent_name(Planner/Researcher/Executor/Critic/Mentor/Reflector,可选)
- **基本流**：1.读agent_run_log 6条按时间轴渲染 2.展开PlanState全量+tool_calls+_patch+citations 3.JSON可复制与折叠 4.关联Task列表联动
- **备选流**：按agent_name过滤单节点；复制单字段->剪贴板
- **异常**：无_patch/citations->置空；JSON过大->虚拟滚动
- **后置**：可一键复制全文用于论文附录
- **验收**：与agent_run_log一致，JSON可一键复制，首绘<300ms，论文取证可用
- **优先级**：P0
