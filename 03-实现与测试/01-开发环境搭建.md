### 6.1 向量模式切换 `USE_PG=1`（pgvector 真 HNSW）

> 实现：`apps/server/app/models/memory.py:17` `_USE_PG_VECTOR = USE_PG==1 and _has_vector` 切 `Vector(1536)` vs `Text(JSON)`，`apps/server/app/core/database.py:12,39-53,126-136` 自动 `CREATE EXTENSION vector` + `CREATE INDEX ... USING hnsw (embedding vector_cosine_ops) WITH (m=16, ef_construction=64)`，`apps/server/alembic/versions/002_vector_idx.py:40-42` 迁移幂等

| 模式 | 环境 | 存储 | 索引 | 检索 | 适用 |
|------|------|------|------|------|------|
| `USE_PG=0` 默认 | SQLite `data/app.db` | `TEXT(JSON)` | `idx_memory_user_type` 通用 | `app/services/memory.py:82-125` 内存 `cosine()` + 衰减 | 无 Docker/CI |
| `USE_PG=1` 生产 | Postgres `pgvector/pg16` | `vector(1536)` | `idx_memory_embedding_hnsw` HNSW (m=16 ef64) | `ORDER BY embedding <=> :vec` 库内向量 | 生产/压测 |

切换：
```bash
# Windows
$env:USE_PG="1"; alembic upgrade head; py -m uvicorn app.main:app --port 8000
# Linux/Mac
USE_PG=1 alembic upgrade head && USE_PG=1 python -m uvicorn app.main:app --port 8000
# 验证
py scripts/pgvector_bench.py --n 500 --q 20   # 期望 p95 <200ms，已验 106ms PASS
py scripts/pgvector_bench.py --n 5000 --q 100 # USE_PG=1 下 p95 <200ms
```

### 6.2 MCP stdio 真实占位

> 实现：`apps/server/app/mcp/client.py:42-65,335-366` mock 3 servers + 3次退避，`mcp.json:2-6`

当前 `mcp.json` 为 `command: mock` 零依赖演示。真实 stdio 仅需改 `mcp.json`：
```json
{
  "servers": {
    "calendar": {"command": "npx", "args": ["-y","calendar-mcp"], "tools": ["create_event","list_events"]},
    "todo": {"command": "npx", "args": ["-y","todo-mcp"], "tools": ["create_todo","complete_todo"]},
    "search": {"command": "npx", "args": ["-y","search-mcp"], "tools": ["web_search"]}
  }
}
```
并在 `app/mcp/client.py:_call_once()` 的 `handler is None` 后插入 `mcp.ClientSession` stdio 调用，保留超时/重试/`AgentRunLog`。详见 `apps/server/README.md#MCP 工具链 + 真实 stdio 占位`。

## 7. 常见问题

- better-sqlite3编译失败 -> `pnpm rebuild` 或 `npm_config_arch`，失败则降级electron-store
- Neo4j内存 -> Docker限 `mem_limit: 2g`
- 端口占用 -> 改`docker-compose ports`
