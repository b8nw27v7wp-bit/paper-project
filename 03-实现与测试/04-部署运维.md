# 部署运维

> 版本：v0.3_20260822 | 03-实现与测试 | 详细版

## 1. 构建

```bash
pnpm build              # frontend dist
docker build -t learning-agent-server ./server
pnpm electron:build --win --x64  # 安装包
```

## 2. 发布

- Web：Docker Compose上云，Nginx反代
- 桌面：NSIS安装包，含sidecar，首次启动初始化PG

## 3. 监控

- /health, Langfuse, 日志agent_run_log

## 4. 备份

- PG每日dump, Neo4j dump
