# 题目与技术栈说明

> 版本：v0.1_20260822

## 1. 题目

**基于多智能体协作与记忆增强的自进化学习任务规划与管理系统 — 融合MCP工具链与多模态感知的知识驱动架构**

### 题目拆解

| 关键词 | 对应实现 | 创新点 |
|--------|----------|--------|
| 多智能体协作 | LangGraph: Planner/Executor/Critic/Mentor | 协作规划，ReAct轨迹可追溯 |
| 记忆增强 | pgvector长期记忆 + 短期上下文 | 个性化召回，消融实验 |
| 自进化 | Reflector + APScheduler周反思 | 规划策略自优化 |
| MCP工具链 | MCP Python SDK + calendar/todo Server | 工具自主调用 |
| 多模态感知 | Electron截图/拍照 + Qwen-VL/Whisper | 课表/错题自动建任务 |
| 知识驱动 | GraphRAG(Neo4j) + pgvector RAG | 证据式规划，先修依赖 |

## 2. 技术栈定版

### 前端
- **Vue3 + Vite + TypeScript**: 组合式API，类型安全
- **Naive UI + Tailwind**: 组件库+原子化，快速搭建
- **FullCalendar + ECharts**: 日历拖拽、甘特图、完成率大屏

### 桌面
- **Electron 40 + electron-builder**: 成熟方案，Codex同款，支持IPC 70方法扩展
- **better-sqlite3**: 同步SQLite存UI状态(automation/thread)
- **node-pty**: 伪终端(预留，学习场景可删减)

### 后端
- **FastAPI + Pydantic + SQLModel**: 高性能API，类型校验，ORM统一
- **LangGraph + MCP Python SDK**: 多Agent编排 + 工具协议
- **PostgreSQL + pgvector**: 业务+向量一库两用，memory_chunk(1536)
- **Neo4j 5**: 知识图谱 PREREQUISITE
- **Redis 7**: 缓存/限流/锁
- **APScheduler**: 周反思定时任务

### 模型
- **DeepSeek-V3/Qwen2.5**: 规划主模型，成本可控
- **Qwen-VL**: 多模态OCR
- **Whisper**: 语音转任务

### 工程
- **pnpm + uv + Docker Compose + electron-rebuild**

## 3. 选型论证

- 为何不用Tauri: 你选Electron，求稳0 Rust学习成本，且Codex官方验证Electron+Node+ Rust CLI链路
- 为何不用SpringBoot: AI生态在Python，单FastAPI工作量最小，论文可写微服务网关时再加SpringBoot壳
- 为何pgvector一库两用: 减少运维，PG16+pgvector 0.7已支持HNSW，满足毕设量级

## 4. 三端形态

Vue同代码 `build:web`出Web，`build:electron`出桌面；CLI(Typer+Rich)仅做trace只读，降低三端成本。
