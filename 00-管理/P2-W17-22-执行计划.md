## 1. 目标

**交付**：Electron 安装包 (sidecar FastAPI) + MCP 2个 + 多模态拍照/语音 + Typer CLI + 周反思调度，打通Web/桌面/CLI三端同一后端。

**验收**：
- [ ] `pnpm electron:build --dir` 产出可执行目录，`externalBin` 带 `server` sidecar，随App启动
- [ ] `better-sqlite3` 存窗口状态/托盘，失败降级 `electron-store` 已有
- [ ] MCP `mcp.json` 可插拔，`POST /mcp/call` 调 `calendar`/`todo` 成功>95%
- [ ] `POST /multimodal/ocr` Qwen-VL mock 课表 `JSON{course,time}` 置信>0.6
- [ ] `POST /multimodal/asr` Whisper mock `WER<15%`
- [ ] `GET /reflection/week` + `POST /reflection/run` 周报 + `APScheduler 0 23 * * 0` 自动
- [ ] `Typer CLI` `planner trace --goal 1` 可查协作轨迹，三端数据一致

## 2. 策略

- **桌面**：`electron-builder` `extraResources: server` + `Node sidecar` `spawn(uvicorn)`，`preload` 注入 `Authorization`
- **存储**：`better-sqlite3` 首次 `electron-rebuild`，失败回退 `electron-store` (已实现)
- **MCP**：Python `mcp` SDK `stdio` 调 `calendar-mcp` mock Server，超时5s重试1
- **多模态**：`Qwen-VL`/`Whisper` 无Key时 mock 课表/语音，确保演示
- **反思**：`APScheduler` 读 `task_execution_log` 算完成率/拖延率，LLM生成 `analysis+patch`
- **CLI**：`app/cli` 复用 `httpx` 调 `GET /plans/{trace}/logs`
