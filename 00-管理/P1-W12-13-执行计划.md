# P1 W12-13 执行计划 — 长期记忆 (pgvector)

> 版本 v0.1_20260823 | 前置 P1-W9-11多Agent | 依据 03-M2 + 04-DB memory_chunk + 05-API Memory

## 1. 目标与验收

**目标**: 任务完成后自动沉淀记忆，规划前Top5召回注入Planner，支撑个性化。

**验收**:
- [ ] `POST /memory` + `GET /memory/search?q=&top_k=5` 检索<1s，cosine>0.75 Top5 (HNSW m=16 ef64)
- [ ] 任务 `complete` 后自动摘要→Embedding→入库 `memory_chunk(type=memory, vector 1536)`
- [ ] 规划前 `memory/search` 注入 `graph` 的 `memory` 字段，prompt可见个性化
- [ ] 无PG时SQLite降级：embedding存JSON，内存余弦检索；有PG时走 `vector_cosine_ops`
- [ ] 有/无记忆完成率对比实验B框架就绪

## 2. 策略

- **Embedding** `DeepSeek 1536` 为空时用hash mock 1536维，保证离线可验
- **表** `memory_chunk` 已在 `04-DB:111` 定义，`user_id+type` 索引，`vector(1536)` PG用pgvector，SQLite存 `TEXT(JSON)`
- **写**：`POST /tasks/{id}/complete` 后触发 `memory_service.summarize(task, log)` → `embedding` → Insert
- **读**：`GET /memory/search` + `graph.invoke` 前检索

## 3. 目录

```
app/models/memory.py      # memory_chunk (vector)
app/services/memory.py    # summarize + embed + search
app/api/v1/memory.py      # 2接口
app/services/planner.py   # 注入 memory（待 W12 后）
```

## 4. 设计

- `summarize`: Prompt “拖延Xh因Y，偏好...” → 1句
- `embed`: `openai.embeddings.create(model=text-embedding-3-small)` 失败则 `hash_mock`
- `search`: PG `SELECT ... ORDER BY embedding <=> query OFFSET`；SQLite `cosine(JSON)` 内存算

## 5. 验证

1. `POST /memory` 5条后 `GET /memory/search?q=拖延` Top5<1s
2. `POST /tasks/complete` 后自动+1记忆
3. `pytest test_memory.py` 4用例
