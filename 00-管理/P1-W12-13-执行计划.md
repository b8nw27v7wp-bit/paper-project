## 4. 设计（按代码实际实现）

- `summarize`: Prompt "拖延Xh因Y，偏好..." → 1句摘要
- `embed`: 真 embedding（UnifiedClient 1536维），失败回退 `hash_mock`
- `search`: PG `SELECT ... ORDER BY embedding <=> query`；SQLite `cosine(JSON)` 内存算（`USE_PG=0` 降级链）
- `asearch_memory`（plans 并行检索用）: 真 embedding + 30天指数衰减 + 子串 0.85 补偿
- 与原计划差异：原设计 read 路径为同步 `search_memory`，现新增异步 `asearch_memory` 供 graph researcher 节点 `asyncio.gather` 并行调用；mock 误用问题在 read 异步路径修复
- 与原计划差异：对比实验B框架为 `ab_test_memory`（with/without 同请求对拍），非原计划的独立实验脚本
