# P1 W14-16 执行计划 — RAG知识库 + 知识图谱

> 版本 v0.1_20260823 | 前置 W12-13记忆 | 依据 03-M3 + 04-DB Neo4j + 05-API RAG/Graph

## 1. 目标与验收

**目标**: 上传PDF/图片切块入库，向量+图谱双检索，规划时证据式注入。

**验收**:
- [ ] `POST /rag/ingest` (multipart PDF/JPG/PNG <20M) 切512+overlap50 → pgvector/Sqlite + Neo4j三元组抽取，100页<60s
- [ ] `GET /rag/search?q=&top_k=10&subject=` 向量Top10 + 图谱 `PREREQUISITE` 关联
- [ ] `GET /graph?subject=` 返回 `{nodes, edges}` 供ECharts渲染，<1万节点<3s
- [ ] 规划时自动检索 `vectorDeps`+`graphDeps` 注入Planner，任务带 `citations`

## 2. 策略

- **切块**: `512 + overlap50`，`MinIO` 存原文件 (P0 mock本地 `data/uploads`)
- **Embedding**: 复用 `memory` 的 `embed_text` 1536
- **图谱**: LLM抽 `(Knowledge)-[PREREQUISITE]->(Knowledge)`，无Key时正则 mock，Neo4j无则内存 fallback
- **检索**: 规划前 `rag/search` Top10 + `MATCH PREREQ`，注入 `PlanState.vectorDeps/graphDeps`
