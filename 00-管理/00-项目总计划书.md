# 项目总计划书 - 智能学习任务规划与管理的智能体

> 题目：基于多智能体协作与记忆增强的自进化学习任务规划与管理的智能体 — 融合MCP工具链与多模态感知的知识驱动架构
> 周期：6-7个月 / 28周 | 版本：v0.6_20260908 | 完成度：`P0-P3 94%` (原92%→94% 2026-08-30 双轨工作台) | 路由18组(工作台复用Plan组) 视图18 F15-F17 M7 tests 后端124 passed(+vitest17+e2e1) vite ~7s

## 1. 项目目标

解决传统学习计划静态、通用、无反馈问题，实现可感知-可规划-可执行-可反思的闭环Agent，支撑论文创新与答辩演示。

## 2. 范围与交付物

- 智能体: Studying-Planner，对外单点 `studying`/`POST /plans` 即 SystemAgent ainvoke，对内6子Agent协作
- 交付：Electron桌面App + Web端（同Vue代码）+ CLI Trace工具
- 后端：FastAPI单后端，支撑6大创新
- 文档：开题报告 + 设计文档 + 论文 + 双对比实验报告
- 部署：Docker Compose一键启动 + 桌面安装包
