## 4. 分步实施

### Step1: Monorepo 地基 (根)
- `pnpm-workspace.yaml` 定义 `apps/*` `packages/*`
- `turbo.json` pipeline: `dev` persistent, `build` dependsOn `^build`, `lint`
- 根 `package.json` scripts: `dev`, `dev:web`, `dev:server`, `dev:electron`, `build`
- `.gitignore` + `.nvmrc` (24) + `.env.example` (DATABASE_URL等)
- 初始化 Git 仓库 (可选)

### Step2: Docker Compose
- 文件: `docker-compose.yml` (services: postgres pgvector/pg16, neo4j 5, redis 7-alpine, minio)
- 与 03-01文档一致，补 `volumes` + `healthcheck` + `mem_limit:2g` for neo4j
- 校验: `docker compose config` (无 Docker 时仅语法校验)

### Step3: FastAPI 健康检查
- `apps/server/pyproject.toml` 依赖: fastapi, uvicorn[standard], pydantic, sqlmodel, asyncpg/psycopg, redis, neo4j, alembic, langgraph(预留), mcp(预留), apscheduler, minio
- `app/main.py`:
  - `FastAPI(title="Learning Planner API", version="0.1.0")`
  - CORS 允许 5173 + electron
  - `GET /health` (无前缀) + `GET /api/v1/health` 返回 `{code:200, msg:"ok", data:{status:"ok", version, services:{postgres,neo4j,redis,minio}}}` 首次仅返回 `status:ok` + 尝试 ping 各存储(失败标记 degraded 不阻断)
  - `GET /` 根欢迎
- `app/core/config.py` 从 env 读取 DATABASE_URL 等
- 启动验证: `uv run uvicorn app.main:app --reload --port 8000` 或 `python -m uvicorn`

### Step4: Vue3 前端可启动
- `apps/frontend` 用 `create-vite vue-ts` 模板
- 依赖: vue@3, vue-router, pinia, naive-ui, tailwindcss@3, fullcalendar(预留), echarts(预留), axios
- `vite.config.ts` proxy: `/api` -> `http://localhost:8000`
- 页面: `src/views/HealthCheck.vue` 调 `GET /api/v1/health` 展示状态；`App.vue` 引入 Naive UI `NConfigProvider`
- `tailwind.config.js` + `postcss.config.js`
- 验证: `pnpm dev` -> http://localhost:5173

### Step5: Electron 40 可启动
- `apps/desktop`：
  - `package.json` 含 `electron@40`, `electron-builder`, `better-sqlite3`(可选, 首次可 stub), `concurrently`, `wait-on`
  - `electron/main.ts`: BrowserWindow (contextIsolation:true, sandbox:true, preload), IPC `handle('app:health')`, 窗口加载 `http://localhost:5173` (dev) 或 `frontend/dist` (prod)
  - `electron/preload.ts`: `contextBridge.exposeInMainWorld('electronBridge', {invoke, on})` + zod 校验预留
  - `electron/ipc/handlers.ts` 预留 `plan:create, task:complete` stub
  - 脚本: `dev` 用 concurrently 启动 vite + electron, `build` 用 electron-builder
  - better-sqlite3 编译预案: 首次尝试 `electron-rebuild`，失败则降级为 `electron-store` (文档风险预案)
- 验证: `pnpm electron:dev` 弹出窗口显示与 Web 同源内容
