## 4. 设计（按代码实际实现）

- **Planner**: 注入 goal+preferences+critic_feedback（重规划），输出 `tasks[]`+`milestones`
- **Researcher**: 并行 `asyncio.gather(_mem,_vec,_graph)` 三检索，结果写入 `memory/graphDeps/vectorDeps`（与原计划差异：原4节点无此节点，W12-14 引入）
- **Executor**: 校验并转 `Task` 模型，`citations` 带证据（与原计划差异：citations 由 W14-16 补齐）
- **Critic**: 规则三检（区间重叠>30% / 单日 `sum(hours)>4` / 前置缺失）+ LLM JSON 二次校验 + 熔断（任务>30直接过）；返回 `pass|reject + feedback`
- **Mentor**: 结合 `completion_rate`、拖延史、图谱前置差异生成 `mentor_msg`（与原计划差异：原为 stub 统计，现为真实注入）
- **Reflector**: 修订动作 `reallocate/reduce_load/add_buffer`；与原计划差异：patch 修订同样触发 critic→planner replan 边（2026-09-04 修复，此前修订不回流校验）

边：`START→planner→researcher→executor→critic→ (pass→mentor→END | reject+rewrites<2→planner else mentor→END)`；reflector patch → critic 同规则回流。
