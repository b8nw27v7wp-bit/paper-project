# P1 W9-11 执行计划 — 多智能体协作 (LangGraph)

> 版本 v0.1_20260822 | 前置 P0-W7-8 单Agent已验收 | 依据 03-六大模块M1 + 04-DB agent_run_log + 05-API

## 1. 目标与验收

**目标**: 将单Agent升级为 `Planner→Executor→Critic→Mentor` StateGraph，ReAct轨迹可追溯，支撑论文主创新。

**验收**:
- [ ] `LangGraph StateGraph` 4节点可运行，`POST /plans` 默认走多Agent (单Agent保留 `?mode=single` 降级)
- [ ] `Critic` 规则+LLM双校验：时间重叠>30%或单日>4h或前置缺失 → 驳回并触发Planner重规划≤2轮，拦截率>20% (测试集)
- [ ] `agent_run_log` 每节点落库 `trace_id` 全量 (`input/output/tool_calls`)，`GET /plans/{trace_id}/logs` 可见4条+
- [ ] SSE 扩展事件 `critic_feedback`/`mentor_msg`，首字节<2s
- [ ] 异常：LLM超时重试1次；2轮仍驳回返回最佳版+警告

## 2. 策略

- **LangGraph** `StateGraph(PlanState)`，P1先用规则Critic (不依赖LLM) 保证拦截率可测，后续可切LLM
- **Planner复用** W7-8 `services/planner.py` mock/LLM，Executor负责转 `Task` 结构，Mentor生成激励话术
- **状态** `PlanState: goal,memory,graphDeps,vectorDeps,milestones,tasks,critic_feedback,mentor_msg,rewrites`
- **降级**：`?mode=single` 或 `DISABLE_MULTi=1` 回退单Agent

## 4. 节点设计

- **Planner**: 注入 goal+preferences+critic_feedback (重规划)，输出 `tasks[]` + `milestones`
- **Executor**: 校验并转 `Task` 模型，`planned_start/end` 已在Planner保证
- **Critic**: 规则：① 时间重叠检测 (区间重叠>30%) ② 单日负荷 `sum(hours)>4` ③ 依赖缺失 (暂空)；返回 `pass|reject + feedback`
- **Mentor**: 结合 `completion_rate` 统计 (暂stub) 生成 `mentor_msg`

边：`START→planner→executor→critic→ (pass→mentor→END | reject + rewrites<2 →planner else mentor→END)`

- 复用 `plan_store` 内存，事件扩展
