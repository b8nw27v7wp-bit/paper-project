# P0 W7-8 执行计划 — 单Agent智能规划 + SSE

> 版本 v0.1_20260822 | 前置 P0-W3-6已验收 (Goal/Task CRUD+日历) | 依据 00-总计划§4 + 02-需求F02 + 03-六大模块M1简化版 + 05-API §3.3

## 1. 目标与验收

**目标**: 输入 Goal 一键生成周/日 Task，SSE 流式推送 thought/task_created/done，支撑后续 W9-16 多Agent 扩展。

**验收**:
- [ ] `POST /api/v1/plans` 输入 `goal_id, preferences{hours_per_day:1-8}`，输出 `{trace_id, tasks, mentor_msg, citations}`，首字节<2s，全程<15s
- [ ] `GET /api/v1/plans/stream?trace_id` SSE 事件 `thought/tool_call/task_created/done`，断线 `Last-Event-ID` 可重连
- [ ] `GET /api/v1/plans/{trace_id}/logs` 返回 `agent_run_log` 全量
- [ ] 无 LLM Key 时走本地规则 mock (按 deadline 均摊每天1-2任务)，保证离线可验；有 Key 时调 DeepSeek-V3 (OpenAI兼容)
- [ ] 前端 `/goals` 每行“智能规划”按钮 → SSE 实时日志 → 自动落库并跳 `/calendar` 可见新任务

## 2. 约束与策略

- **栈锁定**：仅用 `openai` SDK 调 DeepSeek (`LLM_BASE_URL` 默认 https://api.deepseek.com)，不新增框架；SSE 用 `sse-starlette`
- **降级**：`LLM_API_KEY` 为空或超时15s重试1次失败 → mock 生成 7天×1-2任务，保证演示不断
- **数据**：沿用 `user_id=1`，复用 `Task.batch` 写入，`citations` 暂空 (后续 M2/M3 注入)
- **日志**：内存 `plan_store:{trace_id}` + 落库 `agent_run_log` (SQLite JSON)，SSE 从内存重放
- **限流**：单用户 10/min 预留 (Redis 未起时内存计数)

## 4. 后端设计

### 4.1 Planner (简化M1)

- 输入: `goal{title,deadline,description}` + `preferences`
- Prompt: `你是学习规划师，按截止 {deadline} 生成 {days} 天周计划，每天 {hours}h，输出 JSON [{title, date, start, end, priority}]`
- mock: `(deadline - today)/每天1-2任务` 均摊 09:00-10:00/14:00-15:00
- 输出: `tasks[]` 带 `planned_start/end` ISO，`mentor_msg` 一句激励

### 4.2 接口

- `POST /plans` 同步生成 tasks 并写 `Task` (batch) + `agent_run_log(trace_id, agent_name=planner, input, output)`，返回 `trace_id`
- `GET /plans/stream?trace_id` SSE `EventSourceResponse`，从 `plan_store` 重放 `thought`→`task_created`→`done`，延时100ms模拟流式
- `GET /plans/{trace_id}/logs` 查 `agent_run_log`

### 4.3 存储

- 复用 `agent_run_log` 表 (已在 04-DB 定义，SQLite JSON)，`plan_store` 内存 dict 仅作SSE重放
- 无需新表，`init_db` 已建

## 5. 前端设计

- `api/plans.ts` `createPlan(goal_id)` + `subscribe(trace_id, onEvent)` (EventSource)
- `GoalsView.vue` 每行加“智能规划” `NButton:loading`，弹窗 `PlanStream.vue` 显示 thought/task 计数，完成后 `message.success` 并跳 calendar
- `PlanStream.vue` 接收 SSE，渲染 `timeline` (thought/tool_call/task_created)，进度条

## 6. 风险

- SSE 跨域/代理: Vite 已代理 `/api`→8000，EventSource 用同源相对路径
- LLM Key 缺失: 已设计 mock 兜底
- SQLite JSON: 存储为 TEXT，读写用 `json.dumps/loads`
