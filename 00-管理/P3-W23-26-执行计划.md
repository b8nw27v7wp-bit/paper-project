## 4. 设计（按代码实际实现）

- **stats 3端点**（stats.py）：`overview` 按 `range=7d|30d` 聚合 `{completion_rate, delay_rate, avg_load}`；`trend` 返回 `{dates, rates, loads}` 时序；`experiment?type=A|B` 路由到 `app/services/stats.py` 的 experiment_a/experiment_b。
- **实验A/B**：A=多Agent vs 单Agent 盲评（t检验，n=30）；B=有记忆 vs 无记忆 7 日对比。与原计划差异：`experiment_blind.py` 数据为 `random.gauss(seed=42)` 模拟生成而非真实采集——框架/统计流程真实，数据源模拟，论文写作时需明确标注（L10）。
- **实验 API**（experiments.py 7端点）：memory-ablation / agent-comparison / graph-evidence / suite，覆盖消融与组件对比的 API 化入口。
- **前端可视化**：DashboardView + LargeScreenView，ECharts 折线（trend）/饼（构成）/图谱（neo4j 关系），FullCalendar 懒加载（动态 import，不进首屏 chunk）。
- **质量门禁**：vue-tsc 严格通过；ruff 17 处非阻断余量（BLE001 裸 except，集中于 mock 回退路径）；⚠️ eslint：前端有 `lint:eslint` 脚本 + `eslint.config.js`，但 devDependencies 无 eslint 依赖，实际不可运行（L7）。
