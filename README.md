## 版本规范

- 文档命名：`序号-中文名.md`，如 `02-系统架构设计.md`
- 版本号：`v0.1_YYYYMMDD`，重大更新递增 `v0.2`
- 周报/会议记录：`YYYYMMDD-主题.md` 或 `YYYYWW-周报.md`
- 变更记录：每份文档末尾留 `## 变更日志`

## 快速开始

1. 阅读 `00-管理/00-项目总计划书.md` 了解排期
2. 阅读 `01-开题与立项/01-题目与技术栈说明.md` 了解选型
3. 按 `02-需求与设计` 顺序完善设计

## 技术栈快照

前端: Vue3 + Vite + TS + Tailwind + Naive UI + FullCalendar + ECharts
桌面: Electron 40 + electron-builder + better-sqlite3 + node-pty
后端: FastAPI + LangGraph + MCP Python SDK + Pydantic + SQLModel
存储: PostgreSQL+pgvector + Neo4j + Redis + APScheduler
